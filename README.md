# المنقذ | mon9D — الموقع التعريفي

موقع تعريفي وتسويقي عربي متجاوب لتطبيق **المنقذ mon9D**. يشرح خدمات المشوار، الطعام، التوصيل السريع والبقالة، ويعرض تجربة العميل وفرصة الكابتن.

## التشغيل المحلي

```bash
npm run dev
```

ثم افتح `http://localhost:3000`.

## البناء

```bash
npm run build
```

يُنشئ الأمر مجلد `dist/` الجاهز للنشر الثابت.

## البنية

- `index.html` — صفحة الهبوط العربية واتجاه RTL.
- `styles.css` — نظام التصميم والاستجابة.
- `script.js` — قائمة الهاتف والتفاعلات الخفيفة.
- `public/` — الشعار، الأيقونة، وصور الخدمات.
- `server.js` — خادم معاينة ثابت بسيط.

الموقع منفصل عن تطبيق Expo/React Native الأصلي الموجود في مشروع `mon9D`.
